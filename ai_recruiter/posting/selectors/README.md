# Selectors for job posting

## Facebook

- **URL in use:** `https://www.facebook.com/business/pages/post-job`
  - The old `https://www.facebook.com/jobs/employer` URL often shows *"This content isn't available"*; the business URL is the correct one for posting jobs.
- **Requirements:** You need a **Facebook Page** (business page), not only a personal profile. Posting jobs is done from the Page.
- If you still see "content unavailable" after login, open the link in your browser when logged in as the Page admin and confirm your account/region can access the tool (some regions may have limits; Facebook Help: [Create a job on Facebook](https://www.facebook.com/help/950184520201886)).

After the correct page loads, if the script can’t find the form fields, inspect the page and update the selectors in `facebook.json` to match the current DOM.
